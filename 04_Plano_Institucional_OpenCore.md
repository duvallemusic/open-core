# Plano Institucional (Rascunho)

## Parceiros prioritários
1. Plataformas de ensino
2. Universidades
3. Empresas
4. Comunidades Open Source

## Proposta de valor
Alunos desenvolvem software real.
Empresas patrocinam problemas reais.
Usuários recebem soluções abertas.

## Modelo sugerido
OpenCore permanece independente.
Parceiros apoiam, mas não controlam o projeto.

## Possíveis fontes de sustentabilidade
Patrocínio
GitHub Sponsors
OpenCollective
Consultoria
Suporte
Treinamentos
